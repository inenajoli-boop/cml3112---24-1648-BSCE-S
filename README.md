# CML3112 Rainfall Analysis
This program loads the supplied CSV and analyses monthly rainfall patterns in Kampala using pandas and matplotlib.

Files: notebook.ipynb, rainfall.csv, README.md
To run: Open notebook in Google Colab and click Runtime -> Restart and Run All.

Engineering problem: In civil engineering, monthly rainfall data could help predict road flooding hotspots to design better drainage in Kampala.

Data needed: Monthly rainfall totals measured by UNMA, plus road elevation and drainage records kept by KCCA, measured monthly.

I fixed a FileNotFoundError by re-uploading the CSV with the correct name.

When I repeated a cell the plot duplicated and the readings value increased. Restart and Run All clears the kernel memory and runs cells from top to bottom to prove it truly works
